# 运行在OpenWrt上的 Py语言完成的 自动登录脚本
- 某学校(不说哪个了)的💩一样的校园网中，个人账号只能使用2个设备登录(老师3个，如何切换套餐可前往```192.168.2.50:8080```自行研究)，因此，使用软路由可实现下挂多设备使用。
- 但是校园网会检测设备开启网络共享的行为，被发现将遭到10分钟的封禁，不可登录。若多次尝试还会被封禁机器网卡MAC。
- 使用软路由的```UA3F```等工具重写UA 固定TTL 固定IPID TCP分片乱序发射等常见规避多设备检测的方法都无济于事。还是会导致时不时遭到封禁。
- 因此，开发出此脚本，通过收集大量账户，在被封禁时无缝切换账号以规避封禁的冷却时间。

## 功能介绍
- 自动在 号池 中选择一个账号登录（至少一个）
- 如果登录的账号遭到封禁（一般为10分钟），自动在号池中选择下一个账号继续登录
- 如果被封禁了MAC地址，自动随机匹配一个MAC地址继续登录（```5E:XX:XX:XX:XX:XX```）
- 在运行终端输出调试信息，在```tty1```设备输出精简调试信息（一般的笔记本改软路由默认屏幕是```tty1```）
- 这是一个单次执行的脚本

## 项目结构
- ```Main.py``` 脚本入口，主要的逻辑
- ```NetworkCheckFunction.py``` 网络检测逻辑。判断是否连接校园网，是否登录失效
- ```AccountsCheckFunction.py``` 账号选择逻辑。根据```LRU```算法选择最久未使用的账号进行登录。调用```loginFunction()```和```change_wlan0_mac()```函数登录和更换mac地址。自动记录账号使用和封禁状态。
- ```loginFunction.py```账号登录操作和MAC地址更换逻辑。并根据门户登录网站返回值判断登录状态。
- ```PrintFunction.py```调试与输出逻辑。在终端和```tty1```设备输出调试信息，提供状态反馈。
---
- ```accountList.py```储存账号与密码的列表
- ```status.json```记录账号使用时间和封禁状态
---
- ```./TEST/```测试文件夹，存放测试脚本

## 使用方法
- 将res内的文件夹复制到OpenWrt的```/AutoLoginPy```文件夹下

- 在```accountList.py```中添加账号，格式:```{"name": "Name", "id": "88888822601012222", "phone": "13388888888"}```。name为拼音(非必须),id为完整身份证号(取后六位为密码，后六位必须),phone为手机号码(必须)

- 确保软路由有安装```Python```和```requests```库。

```bash
#安装py和requests库的命令如下
opkg update

opkg install python3

opkg install python3-pip

pip3 install requests
```

- 将```*/1 * * * * python /AutologinPy/main.py```添加到```计划任务```中。```*/1```表示每分钟执行一次，推荐配置
